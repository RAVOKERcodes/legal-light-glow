# Chambers of Alka Nupur Singh — Web Application

Official website for the **Chambers of Alka Nupur Singh**, Advocate, Supreme Court of India. Offering focused legal counsel in divorce, family law, child custody, and civil litigation across Delhi NCR.

## Development Setup

Requires Node.js (v18+) and npm.

```sh
# Install dependencies
npm.cmd i   # Or `npm i` if execution policy is enabled

# Start local development server
npm run dev
```

## Tech Stack

- **Framework**: TanStack Start / React / Vite
- **Styling**: Tailwind CSS / Lucide Icons
- **Language**: TypeScript
